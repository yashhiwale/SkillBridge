# SkillBridge - Model 1

## AI/ML Student Career Guidance System

Model 1 is designed for Class 9–10 students.

Its purpose is career exploration and guidance.

It is NOT intended to deterministically predict a student's future career.

## Core Flow

Student Profile
→ Assessment
→ Student Features
→ Career Domain Affinity
→ Sub-domain Exploration
→ Possible Careers
→ Explanation
→ Skill Gaps
→ Possible Pathways

## Current ML Direction

1. Expert knowledge
2. Rule-based baseline
3. Pilot data collection
4. ML experimentation
5. Evaluation
6. Hybrid recommendation system

## Initial Models

- Rule-based scoring
- Logistic Regression
- Random Forest
- XGBoost / Gradient Boosting for comparison

## Responsible AI

The system should:

- Provide multiple career possibilities
- Explain recommendations
- Show strengths
- Show areas for improvement
- Express uncertainty
- Avoid deterministic career assignment
- Avoid sensitive demographic shortcuts
- Support teacher/counsellor review

## Important

Do not invent ground-truth career labels.

Do not claim model accuracy without actual evaluation.
